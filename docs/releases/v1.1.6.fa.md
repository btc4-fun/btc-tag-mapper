# تشخیص دقیق علت خطای قفل تگ

نسخه و کد نصب:

```text
1.1.6
versionCode: 11
```

## مشکل

هنگام قفل کردن تگ، برنامه فقط پیام کلی «عملیات ناموفق یا وضعیت تگ نامشخص است» را نشان می‌داد. این پیام شش علت کاملاً متفاوت را یکسان نمایش می‌داد، پس نه مالک می‌توانست بفهمد چه چیزی شکست خورده، نه از روی گزارش می‌شد علت را تشخیص داد.

## تغییر

`TagProvisioning` اکنون علت شکست را در یک مقدار جدا نگه می‌دارد و رابط کاربری آن را به فارسی روشن نشان می‌دهد:

| علت | پیام |
|-----|------|
| `WRONG_TAG` | تگ نزدیک‌شده همان تگ تأییدشده نیست |
| `CONNECT` | اتصال به تگ برقرار نشد |
| `NOT_WRITABLE` | تگ قابل نوشتن نیست؛ قبلاً قفل شده یا فقط‌خواندنی است |
| `TOO_SMALL` | ظرفیت تگ برای این پیوند کافی نیست |
| `CANNOT_LOCK` | این تگ قفل دائمی NDEF را پشتیبانی نمی‌کند |
| `CONTENT_MISMATCH` | محتوای تگ با پیوند تأییدشده یکسان نیست |
| `LOCK_REJECTED` | تگ فرمان قفل را نپذیرفت |
| `STILL_WRITABLE` | تگ هنوز قابل نوشتن است؛ قفل تأیید نشد |
| `IO` | خطای ورودی/خروجی؛ وضعیت تگ نامشخص است |

منطق امنیتی تغییر نکرده است: هر علت همچنان به وضعیت `FAILED_UNKNOWN` می‌رسد، هیچ تلاش دوبارهٔ خودکاری انجام نمی‌شود، و قفل فقط پس از نوشتن و بازخوانی موفق در همان نشست مجاز است. ترتیب بررسی‌ها هم حفظ شده است.

## آنچه این نسخه انجام نمی‌دهد

این نسخه علت خطای قفل را **قابل تشخیص** می‌کند، نه اینکه آن را رفع کند. علت واقعی خطای قفل روی تگ مالک هنوز تأیید نشده است. پس از نصب این نسخه، پیام دقیق روی صفحه مشخص می‌کند کدام مرحله شکست می‌خورد و آن‌گاه می‌شود دربارهٔ رفع آن تصمیم گرفت.

## آزمون

```text
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --no-daemon
BUILD SUCCESSFUL
app:  65 tests, 0 failures
core: 40 tests, 0 failures
```

آزمون‌های تازه:

- `failureReasonNamesTheExactFailingStep` — تگی که قفل را پشتیبانی نمی‌کند علت `CANNOT_LOCK` می‌دهد و هیچ قفلی انجام نمی‌شود.
- `wrongTagAndContentMismatchAreReportedSeparately` — تگ اشتباه و محتوای نامنطبق دو علت جدا می‌دهند.

## آنچه تأیید نشده است

- علت واقعی خطای قفل روی تگ مالک تأیید نشده است.
- خواندن، نوشتن یا قفل فیزیکی تگ روی گوشی واقعی تأیید نشده است.
- تست روی آیفون واقعی در این تغییر انجام نشده است.
