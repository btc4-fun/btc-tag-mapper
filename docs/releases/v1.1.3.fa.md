## آزمون و حدود

نتیجهٔ بررسی این محیط:

```text
python3 -B -m unittest discover -s tools -p 'test_*.py' -v: 19 passed
```

بررسی مستقل پس از اجرای عامل: ساخت با ابزار نصب‌شدهٔ میزبان انجام شد. محدودیت محیط جداشدهٔ عامل، نقص محصول نبود. هسته، رابط، بررسی ایستا و ساخت آزمایشی موفق شدند؛ گزارش‌های آزمون شامل ۹۷ آزمون بدون شکست است.

```text
JAVA_HOME=/usr/lib/jvm/java-17-amazon-corretto
ANDROID_HOME=/home/saeb/android-sdk
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --offline --no-daemon --console=plain
BUILD SUCCESSFUL
```

فایل آزمایشی ساخته شد و سلامت بایگانی آن بررسی شد. این فایل با کلید انتشار امضا نشده و مدرک انتشار عمومی نیست.
