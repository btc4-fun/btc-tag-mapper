# نسخهٔ اول برنامهٔ فروشنده

این برنامه برای ثبت آفلاین شناسهٔ تگ و نشانی عمومی دریافت بیت‌کوین است. پیش از ذخیره، هر دو مقدار را کامل ببینید و تأیید کنید.

- خواندن شناسهٔ تگ و واردکردن نشانی عمومی با نوشتن یا اسکن دوربین.
- نگهداری سوابق روی گوشی و خروجی روزانه در چند فایل، در صورت نیاز.
- جلوگیری از جایگزینی رکوردهای تکراری یا ناسازگار.
- اصلاح وابستگی دوربین که در ساخت قبلی باعث بسته‌شدن صفحهٔ اسکن می‌شد.
- بدون دسترسی اینترنت، کلید خصوصی، واژه‌های بازیابی یا تغییر اطلاعات تگ.

## فایل نصب

فایل زیر برای نصب است:

```text
btc-tag-mapper.apk
```

دو فایل همراه برای بررسی سلامت و امضای فایل نصب هستند:

```text
SHA256SUMS
signing-certificate.txt
```

نام نسخه برای نخستین انتشار رسمی یکدست شده است. کد داخلی افزایش یافته؛ این تغییر به معنی بازگشت کد برنامه به نسخهٔ قدیمی نیست.

```text
versionName: 1.0.0
versionCode: 3
tag: v1.0.0
```

## هشدار نصب و نگهداری اطلاعات

این انتشار با کلید ثابت جدید همین دو برنامه امضا می‌شود. اگر نسخهٔ قبلی با کلید قدیمی یا آزمایشی نصب شده باشد، اندروید اجازهٔ نصب روی آن را نمی‌دهد. برای عبور از این پیام، برنامه را بدون نگهداری خروجی همهٔ سوابق و پذیرش از دست‌رفتن داده‌های محلی حذف نکنید. خروجی گرفتن به معنی وجود امکان بازگردانی خودکار در برنامه نیست.

اثر انگشت عمومی گواهی انتشار:

```text
SHA-256
7c4ccefc998b2407b22c2a7a3bc97e9b5f9baca3089886a5e71dcfef85b0fa3b
```

شناسهٔ تگ قابل کپی است و به‌تنهایی اصالت کیف پول را ثابت نمی‌کند. اسکن دوربین و خواندن تگ روی همهٔ گوشی‌ها تأیید نشده است. آزمون‌های خودکار و بررسی کلاس‌های داخل فایل نصب، جای آزمون دوربین و تگ واقعی را نمی‌گیرند.
